# 3 Hermanos — Punto de venta para joyería

App de escritorio para una joyería: inventario por clave, peso y kilataje, ventas, apartados con abonos, corte de caja e impresión de tickets.

**Stack:** Python · [Flet](https://flet.dev) · SQLite

## Ejecutar

```bash
uv run flet run          # escritorio
uv run flet run --web    # navegador
```

La base de datos SQLite se crea al iniciar la app si no existe.
